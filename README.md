# Networking-Projects
Securing a Multi-Campus Network for ATT College
Cisco Packet Tracer | Computer Networking | Information Security
Project overview
This project presents a proposed secure network design for ATT College, connecting four South African campuses using a hub-and-spoke architecture. Kimberley serves as the central hub, while Bloemfontein, Nelspruit, and Polokwane connect as branch campuses.

The goal is to provide controlled access to shared services while reducing the risk of unauthorised access, intercepted traffic, lateral movement, and service downtime. The accompanying report documents the architecture and recommended security controls. The Cisco Packet Tracer file provides the network simulation; open it to confirm which recommendations have been implemented and tested.

Skills demonstrated
Network topology planning, campus segmentation, routing and switching concepts, access-control design, security architecture, and technical documentation. The actual configurations and tests in the Packet Tracer file provide evidence of hands-on implementation.
